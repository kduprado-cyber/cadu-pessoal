Política de Privacidade - Cadu pessoal

O app "Cadu pessoal" é de uso exclusivo do seu titular, Cadu Prado, para integração particular com a própria conta Google. Não é oferecido ao público nem tem finalidade comercial.

Dados acessados

Com autorização do titular, o app acessa dados da conta Google (como Gmail, Drive e Agenda) apenas localmente, no computador do titular.

Uso e compartilhamento

  • Os dados não são compartilhados, vendidos nem transferidos a terceiros.
  • Os dados não são usados para treinar modelos de inteligência artificial.
  • Os dados são usados somente para as funções pessoais solicitadas pelo titular.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
